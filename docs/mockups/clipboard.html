telmo Clipboard

Mockups for the clipboard popup that replaces Raycast's clipboard history (swift) and CopyQ (mantle). Shown at the real size: 108×26 cells, about 20% bigger than the other popups. Icons in the real popup are Nerd Font glyphs; this page uses look-alikes. Keys on this page: ←→ state.

Keys
↑↓ move · ↵ put it back on the clipboard and close · p pin · x delete · / search · ? help · esc close. Nothing is ever pasted for you.

  

  

    

      
How it works

      
    
        
  • Recording: on swift, Telmo.app (always running) checks the clipboard twice a second. On mantle, a small user service listens with wl-paste --watch. The popup only reads the history.
    • 
        
  • Storage: ~/.local/share/telmo/clipboard/: one small index file, plus images and files kept as separate files. Copying the same thing again moves it to the top instead of adding a duplicate.
    • 
        
  • Limits: the last 50 items for 30 days. Pins don't count and never expire. Each machine keeps its own history.
    • 
        
  • Everything is kept, passwords included. It never leaves the machine; x deletes.
    • 
      

    

    

      
Nix


programs.telmo.clipboard = {
  enable = true;
  maxItems = 50;   # pins don't count
  maxDays = 30;
};

      
Key: fn+C on swift (Raycast's clipboard today), Super+V on mantle (CopyQ today; Super+C also opens CopyQ, so one of them goes away).
