telmo System: main screen concepts

Six effects, live at the real popup size (90×22 cells). In the popup, ← → (or clicking the logo) cycles them; this page does the same. The one you leave on is remembered: reload the page and it comes back. o switches OS.

Switching

      
    
        
  • ← → cycle through the effects. Clicking the logo or the ‹ name › in the corner does the same.
    • 
        
  • The logo decrypts into each new effect, and a row of dots under it shows where you are in the cycle, then fades out after a second.
    • 
        
  • Decrypt is no longer an effect of its own. It's the opening and switching transition for all of them.
    • 
        
  • The bottom-right corner always names the current effect. It's the only addition to the key line.
    • 
      

    

    

      
Remembering your choice

      
    
        
  • Each open is a fresh process, so the choice lives in a file: ~/.local/state/telmo/system.json, written the moment you switch.
    • 
        
  • Nothing from Nix ever writes that file, so a rebuild can't reset it. Home Manager only owns files under ~/.config and the store.
    • 
        
  • Nix sets the starting point only: programs.telmo.system.effect = "rain" is used until you first switch. An effects list can trim the cycle.
    • 
        
  • A small shared state module in the kit (next to the existing cache) does the reading and the atomic write. Other popups can reuse it for things like a last tab.
    • 
      

    

  


  

    

      
Rebuild in the background

      
    
        
  1. Press u. On swift the Touch ID sheet appears (sudo Touch ID is already on). On mantle, hyprpolkitagent asks for the password.
    2. 
        
  2. Telmo.app runs the rebuild on its own, so you can close the popup right away.
    3. 
        
  3. Your effect keeps running and speeds up while it builds; the key line turns into progress. Reopen the popup any time to see it.
    4. 
        
  4. A notification says when it's done or failed. On failure, L opens the log in a terminal.
