telmo System menu

Mockups for a new popup: your own Apple menu, on swift and mantle, laid out like the Network popup. The logos are fastfetch's own, pulled from fastfetch -l macos and -l nixos. Facts are real values from each host except where a caption says "example". Keys on this page: ←→ state, o OS.

Proposal

      
    
        
  • Key: fn+X on swift, Super+X on mantle. Super+X already opens mantle's rofi power menu, so this replaces it. Super+P is the color picker there.
    • 
        
  • New module telmo-system, same kit as the others: mouse, esc, mock mode, status JSON.
    • 
        
  • Keep awake moves into shared code, so the Power popup and this menu show the same timer.
    • 
        
  • Layout matches Network: sections on the left with a one-line status each, the selected section on the right. Action letters (l s r…) work from any section.
    • 
        
  • Rough size: 1 session for About, Power and Keep awake. Apps and Nix add about half a session each.
