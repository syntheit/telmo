Rebuild in the background

      
    
        
  1. Press u. On swift the Touch ID sheet appears (sudo Touch ID is already on in your config). On mantle, hyprpolkitagent asks for the password.
    2. 
        
  2. Telmo.app runs darwin-rebuild switch (or nixos-rebuild) on its own, so you can close the popup right away.
    3. 
        
  3. Progress comes from Nix's JSON log: builds done out of total. Reopen the popup and the bottom line shows it.
    4. 
        
  4. A notification says when it's done or failed. On failure, L opens the log in a terminal.
    5. 
      

      
To check first: that Touch ID sudo works from a process with no terminal. If it doesn't, the popup takes the sudo step and hands off.

    

    

      
My pick

      
Decrypt on open, then Plasma. The logo assembles from noise in under a second, then the colors drift slowly. It's quiet enough to look at every day, and the open is the hacker moment.

      
Rain is the most "hackerman" of the set. It's busier, so I'd keep it for the rebuild: rain while it builds, then the logo settles.

      
Any of these can mix: one effect when it opens, another while idle, another while rebuilding.
