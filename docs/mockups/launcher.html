A plain list with your real app icons. No prompt symbol: the first character picks the mode. Click the popup and type; try zen, t, !, !sl, ?nix ripgrep, 2 ft to cm.

The first character picks the mode

      
    
        
  • letters: apps. a number or =: math. That's all of it most of the time.
    • 
        
  • ! commands: telmo popups, lock, sleep, restart, rebuild, Settings panes. !sl → Sleep.
    • 
        
  • ? search the web or your docs: ?nix ripgrep, ?gh telmo, ?yt …. tab cycles the engine.
    • 
        
  • Help moved off ?: the footer shows the modes; ! alone lists every command.
    • 
      

    

    

      
Shortcuts: one letter per app, everywhere

      
    
        
  • You give your common apps a letter once, in Nix. Ghostty = t, Zen = w, Spotify = s, Telegram = g, Obsidian = o, VS Code = c.
    • 
        
  • That letter becomes a global hotkey: fn T on swift, Super T on mantle. Same letter, both machines.
    • 
        
  • Inside the launcher, typing just the letter puts that app on top: t ↵.
    • 
        
  • The list shows each app's key on the right, so you learn them by using it. Switch the host tab above to see the Linux labels.
    • 
      

    

  

  

    
In Nix

    
programs.telmo.launcher = {
  keys = { t = "Ghostty"; w = "Zen Browser"; s = "Spotify"; g = "Telegram"; o = "Obsidian"; c = "Visual Studio Code"; };
  # hotkey modifier per host: fn on swift (skhd), SUPER on Hyprland
  search = { nix = "https://search.nixos.org/packages?query=%s"; gh = "https://github.com/search?q=%s"; yt = "https://youtube.com/results?search_query=%s"; };
};
